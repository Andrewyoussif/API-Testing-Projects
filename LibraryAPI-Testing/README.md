LibraryAPI – API Testing Project



📌 Project Overview



This project is an API Testing project built using Postman to test a Library API and validate the complete workflow of adding, retrieving, and deleting books.



The project focuses on API validation, automated test execution, request correlation, and response data validation.



🛠️ Tools \& Technologies



\- Postman

\- REST API

\- JavaScript (Postman Tests)

\- JSON

\- GitHub



🔗 API Requests



The collection contains 3 main requests:



1\. Add Book



\- Adds a new book to the library.

\- Validates the API response using automated tests.

\- Extracts the generated Book ID from the response.



2\. Get Book By ID



\- Retrieves the book using the Book ID generated from the Add Book request.

\- Uses Correlation to automatically pass the ID from the previous request.

\- Validates that the returned book data matches the data originally submitted.



3\. Delete Book



\- Deletes the book using the same dynamically generated Book ID.

\- Uses Correlation to automatically pass the ID to the request.

\- Includes automated tests to validate the deletion response.



🔄 Request Correlation



The collection uses request correlation to make the workflow fully automated.



The Book ID generated by the Add Book request is automatically stored and passed to:



\- Get Book By ID

\- Delete Book



This allows the complete collection to be executed sequentially without manually copying or entering IDs.

🧪 Automated Testing



Automated tests were implemented in Postman to validate:



\- HTTP response status codes

\- Response structure

\- Required fields

\- Response data

\- Successful book creation

\- Successful book retrieval

\- Successful book deletion



🔍 Response Data Validation



After creating a book, the returned Book ID is used to retrieve the same book.



The response from Get Book By ID is then compared with the data sent in Add Book to ensure that:



\- The correct book was retrieved.

\- The stored data matches the originally submitted data.

\- The API maintains data integrity between requests.



⚙️ Automated Collection Execution



The collection is designed to run from start to finish automatically:



1\. Create a book.

2\. Capture the generated Book ID.

3\. Retrieve the book using the captured ID.

4\. Compare the retrieved data with the original data.

5\. Delete the book using the same ID.

6\. Validate the responses using automated tests.



This eliminates the need for manual intervention between requests.
